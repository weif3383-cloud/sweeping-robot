# 掃地演算法規劃（2026-11-15，grill-me 討論結果）

| 項目 | 決定 |
|---|---|
| 策略 | 弓字形覆蓋（boustrophedon）；之後升級成自動建圖、繞障礙、補掃 |
| 開發順序 | 先做網頁模擬器（`迭代五_演算法/`），驗證後再上實車 |
| 感測器 | 超音波朝前，8 cm 減速停下；紅外線 ×2 在第一層側面，貼牆碰觸偵測（有效約 2～3 cm）；不加保險桿（GPIO 18/19 預留）；不買 VL53L0X |
| 防跌落 | **暫時沒有**，只能在平地測試、遠離桌邊樓梯 |
| 規劃跑在哪 | 網頁端；ESP32 只走 `P x,y` / `A`，回報感測器資料；穩定後再移植進 ESP32 |
| 場地 | 先 2×2 m 箱子圍場，格子 5 cm，**場地大小自動量**（不用輸入） |
| 找原點 | 起點放任意位置：往前走到牆，左轉走到另一面牆 → 角落＝原點 |
| 路徑 | 行距 20 cm（車寬 24 cm，重疊 4 cm）；每行走到前方牆為止，橫移 20 cm 換行，橫移時前方是牆＝掃完 |
| 座標校正 | 第一次碰牆記下牆的位置，之後碰同一面牆就把座標修正回去 |
| 階段 1 | 空場地，只驗證路徑與校正 |
| 階段 2 | 加障礙物：超音波標記障礙格、繞過或換行；**牆要驗證**（沿牆連續 > 60 cm，且各行終點一致才算牆）；保留「手動輸入場地大小」備案 |
| 已知限制 | 只適用長方形場地；箱子在角落或貼牆時可能量錯 → 靠後續完整建圖（C 方案）處理 |
| 驗收 | 地圖覆蓋率 > 90%；實車終點離模擬值 5 cm 內 |
| 操作 | 開始清掃 / 停止 / 回起點 三個按鈕；走完自動走回起點 |
| 程式結構 | 單一 HTML；規劃程式獨立一段 JS，模擬與實車共用 |
